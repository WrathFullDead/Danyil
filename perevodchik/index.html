Перевод DE → RU

Готово. Нажмите «Старт».

Как пользоваться:

1. Подключите наушники.
2. Положите телефон экраном вверх, микрофоном (низ телефона) к говорящему.
3. Нажмите «Старт» и не блокируйте экран: экран будет гореть сам.

Перевод появляется здесь крупным текстом и звучит в наушнике, с задержкой в несколько секунд.

Первый раз откройте ⚙︎ Настройки: там выбирается режим и вводится бесплатный ключ.

Настройки

Режим
Бесплатный ключ Gemini
  1. Откройте aistudio.google.com/apikey и войдите с аккаунтом Google.
  2. Нажмите «Create API key», скопируйте ключ.
  3. Вставьте его сюда. Карта и подписка не нужны.

По умолчанию gemini-flash-lite-latest: у неё самый большой бесплатный лимит. Если перевод слабый, попробуйте gemini-flash-latest, но её лимита может не хватить на долгое служение.

Ключ хранится только на этом телефоне. В бесплатном режиме Google может использовать присланный звук для улучшения своих сервисов.

Подсказки для перевода

Имена пастора и братьев, название церкви, частые слова. Это сильно помогает распознаванию.

Голос и текст
Для опытных

Только для режима «Лучший». Короче значит быстрее, но больше запросов и меньше контекста. Отрывок режется на паузе в речи.
