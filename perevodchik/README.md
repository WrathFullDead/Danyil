# Переводчик на служении (немецкий / швабский → русский)

Веб-приложение для iPhone: слушает речь через микрофон, переводит на русский по смыслу
и зачитывает перевод в наушник. Текст показывается на экране крупным шрифтом.

## Режимы
| Режим | Что нужно | Качество на швабском |
|---|---|---|
| **Лучший** | бесплатный ключ Gemini | хорошее: Gemini сам слушает звук, учитывает контекст |
| **Средний** | бесплатный ключ Gemini | среднее: распознаёт iPhone, Gemini исправляет ослышки |
| **Простой** | ничего | слабое: распознаёт iPhone, Google переводит дословно |

Бесплатный ключ: <https://aistudio.google.com/apikey> → «Create API key». Карта не нужна.
Ключ хранится только на телефоне (localStorage).

## Установка на iPhone
1. Открыть адрес приложения в **Safari** (нужен https, см. ниже).
2. «Поделиться» → «На экран Домой».
3. Открыть ⚙︎ Настройки → вставить ключ → «Проверить ключ» → «Проверить голос».
4. Если в режиме «Средний»/«Простой» распознавание не работает: Настройки iPhone → Siri → включить, Клавиатура → Диктовка → включить.

## На служении
- Проводные наушники лучше AirPods: с AirPods iPhone может слушать микрофоном наушника, а не телефона.
- Телефон экраном вверх, низом (микрофоном) к колонке или к говорящему, чем ближе, тем лучше.
- Не блокировать экран: приложение само держит его включённым. Яркость можно убавить.
- Задержка перевода 3–8 секунд. Пение и музыка не переводятся.
- В поле «Подсказки» впишите имена пастора и братьев, название церкви: так распознавание точнее.
- Бесплатный лимит Gemini ограничен; счётчик запросов за день есть в настройках. Если лимит кончился, переключитесь на «Простой».

## Публикация
Нужен https (иначе iPhone не даст микрофон). Папка `perevodchik/` лежит в этом репозитории, поэтому
если репозиторий опубликован через Cloudflare Pages (см. README в корне), приложение будет по адресу
`https://<проект>.pages.dev/perevodchik/`. Подойдёт и GitHub Pages.
